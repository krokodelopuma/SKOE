Выполнение

 1. Теоретическая база

Дилатация - операция, увеличивающая площадь светлых областей на бинарном изображении.

Математически для каждого пикселя вычисляется локальный максимум в окрестности, заданной ядром

ТЕ пиксель на выходе становится белым, если в окне 3×3 вокруг него есть хотя бы один белый пиксель исходного кадра. если нет то черным.

2. Описание разработанной системы

dilate_native() двойной цикл - обход каждого пикселя, для каждого извлекается подматрица и проверяется ее максимум. 
dilate_native_numpy() оптимизированная за счет векторизации - вместо поэлементного обхода выполняется 9(=3*3) сдвигов всего исходного массива и берется поэлементный максимум np.maximum.
dilate_opencv() - cv2.dilate

3. Результаты работы и тестирования

Python-цикл (native) == OpenCV : True
NumPy (native)       == OpenCV : True

все три алгоритма выдают одинаковый результат.

Сравнение быстродействия (изображение 584x1279)
Python-цикл (native)  :   2368.371 мс
NumPy (native)        :      1.657 мс
OpenCV cv2.dilate     :      0.131 мс

Использование векторизации в NumPy убирает накладные расходы интерпретатора на циклы, а OpenCV за счет низкоуровневых оптимизаций компилятора C++ опережает чистый Python.
